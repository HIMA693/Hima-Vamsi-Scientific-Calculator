# Hima Vamsi Scientific Calculator

A Scientific Calculator Desktop Application built using **Python** and **CustomTkinter**.

## 🚀 Project Overview

Hima Vamsi Scientific Calculator is a desktop application designed to perform basic and scientific mathematical calculations through a user-friendly graphical interface.

## ✨ Features

- Basic Arithmetic Operations
- Addition, Subtraction, Multiplication and Division
- Modulus and Percentage
- Square and Power Calculations
- Square Root
- Factorial
- Trigonometric Functions
- Logarithmic Calculations
- Mathematical Constants (π and e)
- Calculation History
- Keyboard Support
- Error Handling
- Standard and Scientific Modes

## 🛠️ Technologies Used

- Python
- CustomTkinter
- Math Module
- VS Code

## 💻 Installation

1. Install Python on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/HIMA693/Hima-Vamsi-Scientific-Calculator.git
   ```

3. Open the project folder.
4. Install CustomTkinter:

   ```bash
   pip install customtkinter
   ```

## ▶️ How to Run

Run the following command:

```bash
python calculator_gui.py
```
